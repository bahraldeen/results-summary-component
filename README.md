# Results Summary Component

A responsive results summary component built as a Frontend Mentor challenge using HTML and CSS.

## Overview

The page presents a user's overall result and a summary of four skill categories:

- Reaction: 80 / 100
- Memory: 92 / 100
- Verbal: 61 / 100
- Visual: 72 / 100

The result panel displays a score of **76 out of 100**, along with a short feedback message.

## Built With

- Semantic HTML structure
- CSS Flexbox for layout and alignment
- CSS custom properties for reusable colors and typography
- CSS linear gradients
- A media query for smaller screens
- Hover styling for the Continue button
- Hanken Grotesk font files supplied with the starter project

## Features

- Desktop layout with the result panel and summary panel side by side
- Responsive layout that stacks the panels on screens up to 672px wide
- Color-coded result categories
- Circular score display
- Hover effect on the Continue button

## Getting Started

No build tools or package installation are required.

1. Download or clone this repository.
2. Keep the starter `assets` folder in the project directory so the font and favicon paths continue to work.
3. Open `index.html` in your browser.

## What I Learned

While building this project, I practiced:

- Structuring a page with HTML elements and classes
- Linking an external CSS stylesheet
- Using CSS variables to manage colors
- Using Flexbox to align and distribute elements
- Creating a circular score area with `border-radius: 50%`
- Using a media query to adapt the layout for smaller screens
- Adding a hover state to a button

## What Could Be Improved

- Move the remaining inline color styles in the HTML into reusable CSS classes.
- Check keyboard focus styling for interactive elements.
- Compare the final page against both supplied reference designs and fine-tune spacing, typography, and responsive behavior.
- Optionally use the supplied `data.json` file to populate the scores dynamically.
